What this proves today

The live demo uses the team’s own signer-separated hello/thank-you model. It reached 85.7% overall accuracy on 63 clips from a teammate excluded from training; accepted predictions reached 91.5% accuracy at the configured confidence gate. This is a scoped two-sign MVP, not unrestricted ISL translation.
